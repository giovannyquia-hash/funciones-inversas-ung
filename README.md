# Funciones inversas · Universidad Nueva Granada

Página de práctica de Matemáticas Básicas con **30 competencias** sobre:

- Relación entre una función y su inversa
- Halla la regla de la función inversa
- Gráficas y simetría respecto a y = x
- Composición, verificación y aplicaciones

## Uso local

Abre `index.html` en cualquier navegador. No requiere instalación ni servidor.

## Funcionalidades

- Buscador de competencias.
- Pregunta de ejemplo al pasar el cursor.
- Práctica con respuestas aleatorias y retroalimentación.
- Gráficas SVG con la recta guía `y = x`, rectas inversas, parábolas y raíces cuadradas.
- Puntuación guardada en `localStorage`.
- Resumen de fórmulas de la función inversa.
